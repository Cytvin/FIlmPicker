# FilmPicker

FilmPicker — веб-приложение для совместного выбора фильма. Создайте комнату, пригласите другого пользователя и независимо отмечайте фильмы, которые вам нравятся или не нравятся. Когда оба участника поставят положительную оценку одному фильму, он появится в списке совпадений.

## Возможности

- регистрация и вход пользователей;
- создание комнаты и приглашение другого зарегистрированного пользователя;
- принятие или отклонение приглашений;
- подбор фильмов через API Кинопоиска;
- настройка подбора по диапазону рейтинга Кинопоиска, годам выпуска, типу, жанрам и минимальному числу голосов;
- индивидуальные оценки «нравится» / «не нравится» для каждого участника;
- просмотр фильмов, понравившихся обоим участникам, со ссылками на страницы Кинопоиска;
- хранение пользователей, комнат, настроек и оценок в базе данных.

## Как устроен подбор

Для комнаты задаются параметры фильтрации. Приложение запрашивает подходящие фильмы у Kinopoisk API, показывает участникам фильмы по одному и сохраняет их оценки. Список совпадений формируется из фильмов, которым оба участника поставили отметку «нравится».

## Технологии

- C# и ASP.NET Core MVC на .NET 8;
- ASP.NET Core Identity для учётных записей;
- Entity Framework Core и SQL Server для хранения данных;
- Kinopoisk API для поиска фильмов;
- Razor, Bootstrap, JavaScript, HTML и CSS для веб-интерфейса;
- Docker для контейнерной сборки и запуска.

## Структура решения

- `FIlmPicker/` — веб-приложение, MVC-контроллеры, представления, модели, сервисы и миграции БД;
- `KinopoiskAPI/` — клиент и модели для взаимодействия с Kinopoisk API;
- `SamOtpravilEmailSender/` — компонент отправки электронной почты через SMTP;
- `Dockerfile` — многоэтапная сборка контейнера приложения.

## Настройка

Приложению нужны база данных SQL Server и API-ключ Kinopoisk API. В режиме разработки используются параметры конфигурации `ConnectionStrings:DefaultConnection` и `KinopoiskAPIKey`. Перед запуском задайте их локально, например через User Secrets; не добавляйте реальные ключи и пароли в Git.

В production приложение ожидает следующие переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `SQL_CONNECTION_STRING` | Строка подключения к SQL Server |
| `KINOPOISK_API_KEY` | Ключ Kinopoisk API |
| `SMTP_SERVER` | SMTP-сервер |
| `SMTP_PORT` | Порт SMTP-сервера |
| `SMTP_SENDER_NAME` | Имя отправителя |
| `SMTP_SENDER_EMAIL` | Адрес отправителя |
| `SMTP_LOGIN` | Логин SMTP |
| `SMTP_PASSWORD` | Пароль SMTP |

При старте приложение применяет миграции Entity Framework Core к настроенной базе данных.

## Запуск в Docker

Сборка образа из корня репозитория:

```bash
docker build -t filmpicker .
```

Контейнер слушает порт `8080`. Для запуска передайте перечисленные выше переменные окружения и строку подключения к доступной базе SQL Server:

```bash
docker run --rm -p 8080:8080 \
  -e SQL_CONNECTION_STRING="<строка подключения>" \
  -e KINOPOISK_API_KEY="<ключ API>" \
  -e SMTP_SERVER="<SMTP-сервер>" \
  -e SMTP_PORT="<порт>" \
  -e SMTP_SENDER_NAME="<имя отправителя>" \
  -e SMTP_SENDER_EMAIL="<адрес отправителя>" \
  -e SMTP_LOGIN="<логин>" \
  -e SMTP_PASSWORD="<пароль>" \
  filmpicker
```

После запуска откройте `http://localhost:8080`.
